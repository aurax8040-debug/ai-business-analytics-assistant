# 公开数据与安全说明

## 已执行的隔离

- 公开版使用新的 Git 历史，不继承私有开发仓库的旧提交。
- 未复制 `.env`、运行日志、浏览器快照、历史报告或原始上传文件。
- 企业、客户、客户集团、门店、员工、SKU、供应商、订单号与业务标识全部重新映射。
- 经营数量、金额、成本、毛利、预算和库存均重新扰动或由固定种子生成。
- SFA 原始 JSON 已替换为公开 Mock 标记，不保留源字段载荷。
- 应用默认只读取仓库内 Mock 数据，不自动发现父目录中的数据库。

## 禁止提交

- `.env`、API Key、Token、密码、私钥。
- 数据库连接串、内部 URL、个人绝对路径。
- 真实企业、客户、门店、员工、SKU 或经营明细。
- 原始 Excel/CSV/PDF、聊天记录、运行日志和未脱敏截图。

提交前运行：

```bash
python3 tools/verify_public_release.py
```

该检查是发布门禁之一，但不能替代人工审查和 GitHub Secret Scanning。
